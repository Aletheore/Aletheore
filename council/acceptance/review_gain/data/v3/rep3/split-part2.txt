5. `pyrsistent/pyrsistent/_plist.py:128` — `_PListBase.split`. The optimization returns the whole list on the left precisely when the right side still contains elements. Use `if not right_list` for the optimization.
6. `pyrsistent/pyrsistent/_pvector.py:55` — `PythonPVector.__getitem__`. The `or` makes slices such as `v[:2]` and `v[::-1]` return the original vector. Require all three slice components to be `None` for this shortcut.
7. `funcy/funcy/seqs.py:357` — `_cut_seq`. Window starts begin at index `1`, skipping the first element and potentially dropping the only full window. Start the range at `0`.
8. `funcy/funcy/seqs.py:367` — `_cut_iter`. When `step > n`, the iterator takes consecutive windows without skipping the gap. Use `elif step == n` so that `step > n` reaches the branch that skips `step - n` items.
9. `pyrsistent/pyrsistent/_pvector.py:295` — `PythonPVector._do_set`. The leaf check is reversed, so setting a trie-backed element overwrites a child pointer or raises `IndexError`. Write the value when `level == 0` and descend at higher levels.
10. `funcy/funcy/debug.py:147` — `format_time`. The milliseconds branch is unreachable because its `sec < 0` test follows the smaller-unit checks. Use `sec < 1` so durations from one millisecond up to one second display in milliseconds.
11. `pyrsistent/pyrsistent/_pvector.py:393` — `PythonPVector._push_tail`. `_count` points one position past the full tail being inserted. At a subtree boundary, this puts the tail under the next child and corrupts indexed reads. Compute the child index from `self._count - 1`.
12. `funcy/funcy/objects.py:54` — `wrap_prop`. The wrapper checks for `__del__`, which handles finalization. Property deletion uses the descriptor method `__delete__`. Check for, define, and delegate to `__delete__` so `del obj.attr` invokes the property deleter inside the context manager.
13. `funcy/funcy/objects.py:29` — `cached_readonly`. Defining `__set__` makes this a data descriptor, so subsequent reads still call the inherited getter and recompute the value. Have `__get__` check the instance cache before calling the getter, while retaining the write guard.
14. `funcy/funcy/debug.py:204` — `_format_error`. `log_calls` and `log_exits` catch `BaseException`, but the formatter only handles `Exception`. A `KeyboardInterrupt` or `SystemExit` is treated as a preformatted message and loses its traceback even with `stack=True`. Check for `BaseException`.
15. `pyrsistent/pyrsistent/_precord.py:125` — `_PRecordEvolver.set`. The factory allowlist is checked against the field descriptor, so a set of field names silently skips the selected factories. Test `key in self._factory_fields`.
16. `pyrsistent/pyrsistent/_plist.py:170` — `_PListBase.__getitem__`. The open-ended slice shortcut passes negative starts directly to `_drop`, so `plist([1, 2, 3])[-1:]` raises `IndexError`. Normalize the start against the list length or let negative starts use the general slicing path.
