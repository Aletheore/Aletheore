1. **`networkx/algorithms/shortest_paths/generic.py`, `_build_paths_from_predecessors`, line 709:** `path[::-0]` raises `ValueError` because a slice step cannot be zero. It should be `path[::-1]`. This breaks all callers that enumerate shortest paths.

2. **`networkx/algorithms/shortest_paths/unweighted.py`, `_single_shortest_path`, line 420:** The loop uses `or` instead of `and`. 3. **`networkx/algorithms/tree/mst.py`, `kruskal_mst_edges`, line 259:** The simple-graph branch returns when `edges_added != edges_needed`, usually after its first edge. Use `==`, as in the multigraph branch. This affects default minimum and maximum spanning trees.

8. **`networkx/algorithms/components/connected.py`, `number_connected_components`, line 147:** Summing zero for each component always returns zero. Sum `1` for each component.

9. **`networkx/algorithms/components/weakly_connected.py`, `number_weakly_connected_components`, line 107:** This likewise sums zero for every component. Sum `1` instead.
