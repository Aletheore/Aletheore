# Contributing

Pull requests are welcome. Development is driven by the maintainer, who is the
only one who merges, so review can take a while and a PR may be closed if it
doesn't fit the project's direction.

## Opening a pull request

You don't need to open an issue first. To send a PR:

1. Follow the [pull request template](.github/pull_request_template.md),
   including the test plan and checklist.
2. Sign off every commit (`git commit -s`) to certify the
   [Developer Certificate of Origin](https://developercertificate.org/). That is
   the only paperwork needed.

## What else is welcome

- **Bug reports and feature proposals** via [GitHub
  Issues](https://github.com/Aletheore/Aletheore/issues) — the issue
  templates cover bug reports, documentation gaps, and proposals.
- **Security reports** — see [SECURITY.md](SECURITY.md), not a public issue.
- **Questions and discussion** via [GitHub
  Discussions](https://github.com/Aletheore/Aletheore/discussions).
