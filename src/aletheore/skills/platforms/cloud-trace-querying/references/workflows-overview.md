# GCP Trace Querying Workflows

Follow these step-by-step guides to diagnose latency, investigate errors, select
query methods, or configure tracing MCP tools.

## Workflows

*   [Trace Querying Decision Tree](./decision-tree.md):
    Decision-making tree to select local scripts, MCP tools, or Observability
    Analytics.
*   [Troubleshoot Slow Requests](./troubleshoot-latency.md): Guides you
    through identifying latency bottlenecks, sequential execution overhead, and
    parallel fan-out delays using Trace timelines.
*   [Find Correlated Logs](./correlated-logs.md): Walkthrough of pulling
    application logs matching a specific trace ID to diagnose errors and runtime
    exceptions.
*   [Generate Console Deep Links](./console-deep-links.md): Explains how to generate
    deep links to the Cloud Trace Explorer and Cloud Logging for a specific
    trace and span ID.
